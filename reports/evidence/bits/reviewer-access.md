The API is deployed privately to Minikube on the BITS Rocky Linux 9 VM; there is no public URL. If using local it works easily, if using BITS VM desktop terminal, enter the repository at ~/workspace/mlops-assignment1 and run: bash scripts/open_vm_access.sh. Keep that terminal open. The dashboard is at http://127.0.0.1:8090, the selected release's MLflow view is at http://127.0.0.1:5000, and the API Ingress is at http://127.0.0.1:8081 with Host heart-disease.test.

In a second VM terminal, run: .venv/bin/python scripts/smoke_api.py --url http://127.0.0.1:8081 --host heart-disease.test. The valid example returns prediction 0, model version 8bb3330d56912ab6edad-54110720 and confidence 0.774473; invalid input returns HTTP 422. Press Ctrl-C in the access terminal when finished. The Kubernetes deployment remains running.
