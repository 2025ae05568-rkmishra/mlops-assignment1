On the VM of your choice(AWS, GCP, Azure) or any GKE platform you can use to deploy this. This was run on minikube cluster on bits VM but can be run anywhere. 
Open ~/workspace/mlops-assignment1 and run bash scripts/open_vm_access.sh; keep that terminal open. In another VM terminal run .venv/bin/python scripts/smoke_api.py --url http://127.0.0.1:8081 --host heart-disease.test. Expect prediction 0, model 8bb3330d56912ab6edad-54110720, and invalid_status 422. In the VM browser open http://127.0.0.1:8090 for monitoring and http://127.0.0.1:5000 for MLflow. These URLs are private to the VM.
